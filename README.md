\# Conecta Solidária



\## Sobre o projeto



O Conecta Solidária é um projeto acadêmico de desenvolvimento Front-End. Nesta etapa, o projeto foi organizado com controle de versões, documentação técnica e melhorias de acessibilidade.



\## Tecnologias utilizadas



O projeto foi desenvolvido utilizando:



\- HTML5 para a estrutura das páginas;

\- CSS3 para estilização e recursos de acessibilidade;

\- JavaScript para funcionalidades e interações;

\- Git para controle de versões;

\- GitHub para gerenciamento do repositório.



\## Estrutura do projeto



O projeto está organizado nas seguintes pastas:



\- `html` - arquivos das páginas da aplicação;

\- `css` - arquivos de estilos;

\- `js` - arquivos JavaScript;

\- `imagens` - recursos visuais utilizados no projeto.



\## Como executar localmente



1\. Baixe ou clone o repositório.

2\. Abra a pasta do projeto no computador.

3\. Acesse a pasta `html`.

4\. Abra o arquivo `index.html` em um navegador.

5\. Não é necessária instalação de dependências adicionais.



\## Acessibilidade



Foram implementadas melhorias de acessibilidade, incluindo foco visível para navegação por teclado e suporte a `prefers-reduced-motion`, reduzindo animações e transições para usuários que preferem menos movimento.



\## Versionamento



O projeto utiliza Git e GitHub seguindo uma estratégia baseada em GitFlow.



A branch `master` mantém a versão estável do projeto, a branch `develop` concentra o desenvolvimento integrado e branches `feature`, como `feature/acessibilidade` e `feature/readme`, são utilizadas para novas funcionalidades e melhorias.



As alterações são registradas por meio de commits descritivos e integradas por meio de merges e pull requests.
